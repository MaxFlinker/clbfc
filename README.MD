🇩🇪 BatchFileCreator – Version 1.09
Stabilitätsrelease – 11. Oktober 2026  
Ein Werkzeug zur strukturierten Erzeugung von Datei‑ und Ordnerstrukturen
aus ASCII‑TREE‑Darstellungen oder MASK‑Definitionen.

🇩🇪 Vorwort der Entwicklungsleitung (11. Oktober 2026)
„Mit Version 1.09 setzen wir die Linie fort, die seit Winter 2026 verfolgt wird:
Stabilität, Ordnung, klare Zuständigkeiten und ein System, das tut, was es soll.“

Die Entwicklungsgeschichte des BatchFileCreator zeigt,
dass die Software seit der ursprünglichen WinForms‑Version (siehe GitHub)
immer wieder mit unklaren Pfadführungen und instabilen TREE‑Strukturen  
zu kämpfen hatte.

Version 1.09 markiert den Punkt,
an dem diese Altlasten endgültig bereinigt wurden.

Kein Humbug.
Keine Ausreden.
Nur Ordnung.

🇬🇧 Executive Summary (English)
BatchFileCreator v1.09 is the first release to fully stabilize
path‑handling, TREE parsing, and FI‑Mode output behavior.
The tool now reliably writes to the user‑defined output directory,
avoids Debug‑folder pollution, and generates complete file structures
without ambiguity.

This release is internally classified as a Stability Release.
